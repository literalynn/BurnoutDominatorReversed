## First initialisation chain to examine

The pseudocode of `entry` at `0x00100008` shows the clearing of global memory in `0x00432B00..0x01F9BB00`, system calls 0x3C/0x3D preparing the thread and the heap, then the initialisation group at `0x003B2BD0`, FlushCache, EI and the call to `0x0021B3F8`.

That last routine contains a wait tied to `0x00207D08` and to a global byte at `0x0051B910`. This is a lead for comparing the runtime's boot traces with PS2/PCSX2. This static reading proves neither that the path executes nor the reason for the wait.

A bounded boot must keep the final PC, any missing target and the first hardware failure. Later changes must be motivated by these traces, then compared with the original game's behaviour.
